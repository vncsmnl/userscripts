# UserScripts

Coleção simples de scripts de usuário para navegador.

## Scripts
- Amazon: adiciona um menu para buscar o título do livro no Z-Lib e no Anna's Archive.
- Paywall: abre o site Paywall Skip para contornar a página de pagamento.
- Vimm's Cheevos: valida arquivos de jogo do Vimm's Lair contra hashes do RetroAchievements.
- YouTube: adiciona uma opção para baixar a thumbnail do vídeo atual.

## Como usar
1. Instale um gerenciador de userscripts, como Tampermonkey ou Violentmonkey.
2. Abra o arquivo .user.js desejado e clique em instalar.
3. Acesse a página correspondente para usar o script.
